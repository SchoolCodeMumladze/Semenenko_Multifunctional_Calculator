# Semenenko_Multifunctional_Calculator
Многофункциональный калькулятор (англ. - Multifunctional Calculator) - проект, в котором собрано множество полезных функций - от обычного калькулятора до генератора надёжного пароля! Проект насчитывает более 300 строк кода.

# Подробнее про проект
Проект создаётся в рамках Школы::Кода. 
Начало разработки - 2 ноября 2025 года
Послденяя версия выпущена 19 декабря 2025 года
21 декабря 2025 года проект стал общедоступным.

# Многообразие функций
На момент релиза в проекте насчитывается 17 различных функций и отдельный раздел с информацией.
Самая объёмная функция проекта - калькулятор дробей. Она насчитывает около 30 строк кода, и ещё не закончена!

# Заключение
Это пробная версия описания проекта. Оно будет дополняться по мере развития самого проекта.
